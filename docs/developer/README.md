## Contributor Scope

These docs are intended to answer:

- how to set up a local environment for development
- how to run the desktop app, CLI, and tests
- where logic belongs in the shared architecture
- how to safely extend the BLE/profile/workflow/plugin boundary
- how the desktop GUI is structured internally
